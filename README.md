## bookstore-frontend

A React.js application developed incrementally through multiple Use Cases(UC). Each use case is implemented in a separate Git branch to demonstrate the progressive development of the application.

## Project Overview

This project repo is the backend part of my FullStack Project, Bookstore Application.

## Branch Structure

| Branch | Description |
|---|---|
| main | Default branch of the repo consisting of the README.md file |
| develop | Contains the initial project structure and integrated development changes |
| feature/UC1-ProjectSetup | Sets up the initial bookstore frontend application structure and connecting the frontend with the backend application |
| feature/UC2-UserAuthentication | Adds user authentication UI in the application |
| feature/UC3-BookManagement | Added UI to add book product and delete or edit book information |
| feature/UC4-RoleBasedAuthorization | Separated Admin and User UI and authorization |
| feature/UC5-BookBrowsing | Adds UI to browse book such as filter, sort and search |
| feature/UC6-ShoppingCart | Adds Shopping cart UI |
| feature/UC7-Wishlist | Adds Wishlist UI |
| feature/UC8-CustomerDetails | Adds UI which enables user to add their personal contact information and delivery address |
| feature/UC9-Order | Adds UI which enables user to place order and for admin to manage them |
